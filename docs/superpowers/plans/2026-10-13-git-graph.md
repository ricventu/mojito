# Git Graph View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only git branch/commit graph, reachable from a project divider, a terminal header and a ticket's launch sheet, with the relevant branch highlighted and its ahead/behind count.

**Architecture:** The server reads raw commits (`git log` with NUL/RS separators), refs (`for-each-ref`) and worktrees, and answers JSON; a pure client module assigns lanes and edges; a dynamic React view renders one SVG strip per row. Routing follows the docs overlay exactly: a standalone view for project/ticket, an overlay inside TerminalView for a session.

**Tech Stack:** Next 16 route handlers, TypeScript, React 19, vitest (node environment only — no jsdom), lucide-react icons, hand-written CSS in `globals.css`.

**Spec:** `docs/superpowers/specs/2026-10-13-git-graph-design.md`

## Global Constraints

- Work on a branch/worktree off `main`; `main` has unrelated uncommitted changes — never stage them.
- Package manager is **pnpm**. Verification is `pnpm typecheck && pnpm test`.
- Imports in `src/server/**` are **extensionless** (`from "./merge"`, never `"./merge.js"`).
- Tests run in node only: anything testable lives in a pure module; hooks/components are glue.
- Client code must never import from `src/server/**` except `import type` (see `useDocs.ts`: server types are re-declared on the client because server modules load `node:*`).
- Icons are lucide, imported per icon, sized with `size={n}`, on controls carrying `.icon`. No Tailwind outside `src/components/ui`.
- Everything is read-only: no `fetch`, no checkout, no ref writes.
- Commit cap per page: **200** (`-n 201` to detect `hasMore`). File list cap: **300**. Git timeout: **10s**.
- Hash validation: `^[0-9a-f]{7,40}$`, checked before any git call.
- Lane cap: **5 below 480px, 12 otherwise**. Row height: **28px**, **40px below 480px** (two-line text).
- Copy is English, sentence case, matching the app's existing strings.

## Review Focus

1. **Branch names with `/`, `,`, `->` or spaces** (`feature/a,b->c`, a project named `Factory Book`) — must render verbatim and round-trip through the url. Pinned in Task 1 (`parseRefs`) and Task 6 (appLocation round trip with a space).
2. **Detached HEAD in a session's worktree** — no highlight, graph still loads. Pinned in Task 3 (`currentBranch` answers null for `HEAD`).
3. **A merge or bulk commit touching more than 300 files** — details list truncates with a `moreFiles` count instead of shipping megabytes. Pinned in Task 2 (`readCommit` with a fake run).
4. **Refs move between "Load more" pages** (a commit pushed meanwhile shifts `--skip`) — the same commit must not render twice. Pinned in Task 7 (`appendPage` dedupes by hash).
5. **A `?commit=` in a shared url naming a commit this repo lacks** — the sheet shows "Commit not found", not a 409 with git's stderr. Pinned in Task 2 (`readCommit` answers null) and Task 4 (route answers 404).

```ts
// src/server/gitGraph.ts
// Reads a repo's commit graph for the git graph view. Pure parsers up top, the git calls
// below over an injected runner — the split worktree.ts uses — so every format detail is
// testable against strings and one integration test checks them against real git.

export type GitText = (args: string[]) => Promise<string>;

export interface GraphRef {
  name: string;
  kind: "local" | "remote" | "tag";
  // Checked out in some worktree (the main checkout included).
  worktree?: true;
  // …and that worktree is one Mojito created, under <repo>/.claude/worktrees/.
  mojito?: true;
}

export interface GraphCommit {
  hash: string;
  parents: string[];
  author: string;
  date: string;
  subject: string;
  refs: GraphRef[];
}

export interface RefEntry { hash: string; ref: GraphRef }

export interface CommitFile { status: string; path: string; from?: string }

export const PAGE_SIZE = 200;
export const MAX_FILES = 300;

// NUL between fields and RS after each record: no subject character can break the parse,
// where `%D` or a printable separator could.
export const LOG_FORMAT = "%H%x00%P%x00%an%x00%aI%x00%s%x1e";

export function parseLog(out: string): Omit<GraphCommit, "refs">[] {
  return out
    .split("\x1e")
    .map((r) => r.replace(/^\n+/, ""))
    .filter((r) => r !== "")
    .map((r) => {
      const [hash, parents, author, date, subject] = r.split("\x00");
      return { hash, parents: parents ? parents.split(" ") : [], author, date, subject: subject ?? "" };
    });
}

// `for-each-ref --format=%(objectname)%00%(*objectname)%00%(refname)`. The middle field
// is set only for an annotated tag, and is the commit it points at — the tag object's own
// hash is in no commit's history, so a tag keyed on it would never be drawn.
export function parseRefs(out: string): RefEntry[] {
  const entries: RefEntry[] = [];
  for (const line of out.split("\n")) {
    if (line === "") continue;
    const [obj, peeled, refname] = line.split("\x00");
    const hash = peeled || obj;
    if (refname.startsWith("refs/heads/")) {
      entries.push({ hash, ref: { name: refname.slice("refs/heads/".length), kind: "local" } });
    } else if (refname.startsWith("refs/remotes/")) {
      const name = refname.slice("refs/remotes/".length);
      // A symref onto a branch already listed — the same commit twice under a name that
      // hides which branch it is.
      if (name.endsWith("/HEAD")) continue;
      entries.push({ hash, ref: { name, kind: "remote" } });
    } else if (refname.startsWith("refs/tags/")) {
      entries.push({ hash, ref: { name: refname.slice("refs/tags/".length), kind: "tag" } });
    }
  }
  return entries;
}

export function markWorktrees(
  entries: RefEntry[],
  worktrees: { path: string; branch: string; prunable?: boolean }[],
): RefEntry[] {
  const live = worktrees.filter((w) => !w.prunable && w.branch !== "");
  return entries.map((e) => {
    if (e.ref.kind !== "local") return e;
    const wt = live.find((w) => w.branch === e.ref.name);
    if (!wt) return e;
    const ref: GraphRef = { ...e.ref, worktree: true };
    if (wt.path.includes("/.claude/worktrees/")) ref.mojito = true;
    return { hash: e.hash, ref };
  });
}

const KIND_ORDER: Record<GraphRef["kind"], number> = { local: 0, remote: 1, tag: 2 };

export function attachRefs(commits: Omit<GraphCommit, "refs">[], entries: RefEntry[]): GraphCommit[] {
  const byHash = new Map<string, GraphRef[]>();
  for (const e of entries) {
    const list = byHash.get(e.hash) ?? [];
    list.push(e.ref);
    byHash.set(e.hash, list);
  }
  return commits.map((c) => ({
    ...c,
    refs: (byHash.get(c.hash) ?? []).slice().sort((a, b) => KIND_ORDER[a.kind] - KIND_ORDER[b.kind]),
  }));
}

export function parseCounts(out: string): { behind: number; ahead: number } {
  const [left, right] = out.trim().split(/\s+/).map((n) => Number.parseInt(n, 10));
  return { behind: left || 0, ahead: right || 0 };
}

// `show --name-status -z`: NUL-separated tokens, a status code followed by one path, or
// two for a rename/copy (R087 old new). -z because without it git C-quotes any path with
// a tab, quote or non-ASCII byte.
export function parseNameStatus(out: string): CommitFile[] {
  const tokens = out.replace(/^[\n\0]+/, "").split("\0");
  const files: CommitFile[] = [];
  let i = 0;
  while (i < tokens.length && tokens[i] !== "") {
    const status = tokens[i][0];
    if (status === "R" || status === "C") {
      files.push({ status, from: tokens[i + 1], path: tokens[i + 2] });
      i += 3;
    } else {
      files.push({ status, path: tokens[i + 1] });
      i += 2;
    }
  }
  return files;
}

// Full or abbreviated lowercase hex only. Anything else never reaches git, so a query
// parameter cannot become a flag or a rev expression.
export function isValidHash(s: string): boolean {
  return /^[0-9a-f]{7,40}$/.test(s);
}
```

```ts
// A scripted runner: the first matching prefix answers; an Error value throws.
function fakeRun(script: [string[], string | Error][]) {
  const calls: string[][] = [];
  const run = async (args: string[]) => {
    calls.push(args);
    const hit = script.find(([prefix]) => prefix.every((p, i) => args[i] === p));
    if (!hit) throw new Error(`unscripted: git ${args.join(" ")}`);
    if (hit[1] instanceof Error) throw hit[1];
    return hit[1];
  };
  return { run, calls };
}
```

```ts
import { execFile } from "node:child_process";
import { promisify } from "node:util";
import { detectDefaultBranch } from "./merge";
import { parseWorktrees } from "./worktree";

const pexec = promisify(execFile);

// Read-only and local, so no credential plumbing: LC_ALL=C pins git's output to English,
// as merge.ts does, and 10s bounds a huge repo without wedging the request.
function defaultRun(cwd: string): GitText {
  return async (args) => (await pexec("git", args, {
    cwd,
    encoding: "utf8",
    timeout: 10_000,
    maxBuffer: 64 * 1024 * 1024,
    env: { ...process.env, LC_ALL: "C" },
  })).stdout;
}

async function attempt(run: GitText, args: string[]): Promise<string | null> {
  try {
    return (await run(args)).trim() || null;
  } catch {
    return null;
  }
}

export interface GraphHighlight {
  branch: string;
  tip: string;
  base: string;
  baseTip: string;
  ahead: number;
  behind: number;
  merged: boolean;
}

export interface GitGraph {
  head: string | null;
  highlight: GraphHighlight | null;
  commits: GraphCommit[];
  hasMore: boolean;
}

export interface CommitDetails {
  hash: string;
  parents: string[];
  author: string;
  email: string;
  date: string;
  message: string;
  files: CommitFile[];
  moreFiles: number;
}

const REF_NAMESPACES = ["refs/heads", "refs/remotes/origin", "refs/tags"];

export async function readGitGraph(
  cwd: string,
  opts: { skip: number; highlight: string | null },
  run: GitText = defaultRun(cwd),
): Promise<GitGraph> {
  // Unguarded: in a directory that is not a repo this is the call that fails, and the
  // route turns the failure into a 409 carrying git's own words.
  const refOut = await run(["for-each-ref", "--format=%(objectname)%00%(*objectname)%00%(refname)", ...REF_NAMESPACES]);
  const head = await attempt(run, ["rev-parse", "--verify", "-q", "HEAD"]);
  let worktrees: ReturnType<typeof parseWorktrees> = [];
  try { worktrees = parseWorktrees(await run(["worktree", "list", "--porcelain"])); } catch { /* no badges */ }
  const entries = markWorktrees(parseRefs(refOut), worktrees);

  // A repo with no commits has neither refs nor a HEAD, and `git log` would fail on it.
  if (entries.length === 0 && head === null) return { head, highlight: null, commits: [], hasMore: false };

  const revs = ["--branches", "--remotes=origin", "--tags", ...(head ? ["HEAD"] : [])];
  const logOut = await run([
    "log", "--topo-order", `--format=${LOG_FORMAT}`, `--skip=${opts.skip}`, "-n", String(PAGE_SIZE + 1), ...revs, "--",
  ]);
  const parsed = parseLog(logOut);
  const commits = attachRefs(parsed.slice(0, PAGE_SIZE), entries);
  const highlight = opts.skip === 0 && opts.highlight ? await highlightStats(cwd, opts.highlight, run) : null;
  return { head, highlight, commits, hasMore: parsed.length > PAGE_SIZE };
}

async function highlightStats(cwd: string, branch: string, run: GitText): Promise<GraphHighlight | null> {
  const tip = await attempt(run, ["rev-parse", "--verify", "-q", `refs/heads/${branch}^{commit}`]);
  if (!tip) return null;
  let def: string | null = null;
  try {
    def = await detectDefaultBranch(cwd, async (args) => ({ stdout: await run(args), stderr: "" }));
  } catch { /* no default branch: the strip names the branch alone */ }
  const none: GraphHighlight = { branch, tip, base: "", baseTip: "", ahead: 0, behind: 0, merged: false };
  if (!def) return none;
  for (const [ref, base] of [[`refs/remotes/origin/${def}`, `origin/${def}`], [`refs/heads/${def}`, def]]) {
    // The default branch measured against itself says nothing.
    if (base === branch) continue;
    const baseTip = await attempt(run, ["rev-parse", "--verify", "-q", `${ref}^{commit}`]);
    if (!baseTip) continue;
    const { ahead, behind } = parseCounts(await run(["rev-list", "--left-right", "--count", `${baseTip}...${tip}`]));
    return { branch, tip, base, baseTip, ahead, behind, merged: ahead === 0 };
  }
  return none;
}

export async function readCommit(cwd: string, hash: string, run: GitText = defaultRun(cwd)): Promise<CommitDetails | null> {
  if (!isValidHash(hash)) throw new Error("invalid hash");
  const full = await attempt(run, ["rev-parse", "--verify", "-q", `${hash}^{commit}`]);
  if (!full) return null;
  const meta = await run(["show", "-s", "--format=%H%x00%P%x00%an%x00%ae%x00%aI%x00%B", full]);
  const [h, parents, author, email, date, message] = meta.split("\x00");
  // A merge lists what it brought in against its first parent — what `git log -p` on the
  // mainline would show — rather than the combined diff, which lists only conflicts.
  const files = parseNameStatus(await run(["show", "--format=", "--name-status", "-z", "-M", "--diff-merges=first-parent", full]));
  return {
    hash: h,
    parents: parents ? parents.split(" ") : [],
    author,
    email,
    date,
    message: (message ?? "").trimEnd(),
    files: files.slice(0, MAX_FILES),
    moreFiles: Math.max(0, files.length - MAX_FILES),
  };
}
```

Note: `full` is the resolved 40-hex hash from `rev-parse`, so the two `show` calls never receive user input.

```ts
// src/server/gitTarget.ts
import { execFileSync } from "node:child_process";
import type { SessionMeta } from "./types";
import { loadProjectMap, resolvePathForProject } from "./projects";
import { repoForTicket, resolveTicketWorktree } from "./ticketCwd";
import { getConfig, getRegistry } from "./app";

export interface GitTargetDeps {
  session: (id: string) => SessionMeta | undefined;
  projectsPath: string;
  // The branch checked out in a directory, or null (detached, or not a repo).
  currentBranch: (cwd: string) => string | null;
}

export type GitTargetResult =
  | { ok: true; cwd: string; label: string; highlight: string | null }
  | { ok: false; error: string; code: 400 | 404 };

// The git graph's three entry points, resolved the way resolveDocsTarget resolves the
// docs' two — a session wins when several are present, as there. "Not a repo" is not
// decided here: the graph read is what finds out, and answers 409 with git's own words.
export function resolveGitTarget(url: URL, deps: GitTargetDeps): GitTargetResult {
  const q = url.searchParams;
  const session = q.get("session");
  if (session) {
    const meta = deps.session(session);
    if (!meta) return { ok: false, error: "unknown session", code: 404 };
    // As docs: a session's cwd is frozen at launch, and a ticket's worktree may have
    // appeared since — prefer it, and never downgrade a cwd already inside one.
    const worktree = meta.ticket
      ? resolveTicketWorktree(deps.projectsPath, meta.ticket, meta.projectName ?? null)
      : null;
    const cwd = worktree ?? meta.cwd;
    if (!cwd) return { ok: false, error: "session has no working directory", code: 400 };
    return { ok: true, cwd, label: meta.ticket || meta.title, highlight: deps.currentBranch(cwd) };
  }
  const ticket = q.get("ticket");
  if (ticket) {
    const project = q.get("project") || null;
    const worktree = resolveTicketWorktree(deps.projectsPath, ticket, project);
    if (worktree) return { ok: true, cwd: worktree, label: ticket, highlight: deps.currentBranch(worktree) };
    let repo: string | null = null;
    try { repo = repoForTicket(deps.projectsPath, ticket, project); } catch { /* malformed id */ }
    if (!repo) return { ok: false, error: "unknown ticket", code: 404 };
    return { ok: true, cwd: repo, label: ticket, highlight: null };
  }
  const project = q.get("project");
  if (project) {
    const path = resolvePathForProject(loadProjectMap(deps.projectsPath), project);
    if (!path) return { ok: false, error: "unknown project", code: 404 };
    return { ok: true, cwd: path, label: project, highlight: null };
  }
  return { ok: false, error: "project, session or ticket required", code: 400 };
}

export function currentBranch(cwd: string): string | null {
  try {
    const name = execFileSync("git", ["rev-parse", "--abbrev-ref", "HEAD"], {
      cwd, encoding: "utf8", stdio: ["ignore", "pipe", "ignore"],
    }).trim();
    return name && name !== "HEAD" ? name : null;
  } catch {
    return null;
  }
}

export function gitTargetDeps(): GitTargetDeps {
  return { session: (id) => getRegistry().get(id), projectsPath: getConfig().projectsPath, currentBranch };
}
```

Note: `ticket` is checked before `project` because a ticket query carries `project` as its disambiguator.

```ts
import { NextResponse } from "next/server";
import { getConfig } from "@/server/app";
import { tokenFromHeaders } from "@/server/auth";
import { gitTargetDeps, resolveGitTarget } from "@/server/gitTarget";
import { readGitGraph } from "@/server/gitGraph";
import { gitFailureDetail } from "@/server/worktree";

// One page of a repo's commit graph. Read-only: it never fetches, so it shows whatever
// the last fetch left.
export async function GET(req: Request) {
  const cfg = getConfig();
  if (!tokenFromHeaders(req.headers, cfg.token)) return new NextResponse("unauthorized", { status: 401 });
  const url = new URL(req.url);
  const target = resolveGitTarget(url, gitTargetDeps());
  if (!target.ok) return NextResponse.json({ error: target.error }, { status: target.code });
  const skip = url.searchParams.get("skip") ?? "0";
  if (!/^\d+$/.test(skip)) return NextResponse.json({ error: "invalid skip" }, { status: 400 });
  try {
    const graph = await readGitGraph(target.cwd, { skip: Number(skip), highlight: target.highlight });
    return NextResponse.json({ label: target.label, ...graph });
  } catch (e) {
    return NextResponse.json({ error: gitFailureDetail(e) }, { status: 409 });
  }
}
```

```ts
import { NextResponse } from "next/server";
import { getConfig } from "@/server/app";
import { tokenFromHeaders } from "@/server/auth";
import { gitTargetDeps, resolveGitTarget } from "@/server/gitTarget";
import { isValidHash, readCommit } from "@/server/gitGraph";
import { gitFailureDetail } from "@/server/worktree";

// One commit's message and changed files, for the graph's details sheet. The hash is
// validated before anything else runs, so a query value can never reach git as a flag.
export async function GET(req: Request) {
  const cfg = getConfig();
  if (!tokenFromHeaders(req.headers, cfg.token)) return new NextResponse("unauthorized", { status: 401 });
  const url = new URL(req.url);
  const hash = url.searchParams.get("hash") ?? "";
  if (!isValidHash(hash)) return NextResponse.json({ error: "invalid hash" }, { status: 400 });
  const target = resolveGitTarget(url, gitTargetDeps());
  if (!target.ok) return NextResponse.json({ error: target.error }, { status: target.code });
  try {
    const details = await readCommit(target.cwd, hash);
    if (!details) return NextResponse.json({ error: "unknown commit" }, { status: 404 });
    return NextResponse.json(details);
  } catch (e) {
    return NextResponse.json({ error: gitFailureDetail(e) }, { status: 409 });
  }
}
```

```ts
// src/lib/gitGraph.ts
// The git graph's lane layout — pure, so the drawing rules are testable in the node-only
// setup; GitGraphView only paints what this answers.

// Mirrors of src/server/gitGraph.ts, declared again rather than imported: that module
// loads node:child_process and has no business in the browser bundle (as useDocs.ts).
export interface GraphRef { name: string; kind: "local" | "remote" | "tag"; worktree?: true; mojito?: true }
export interface GraphCommit { hash: string; parents: string[]; author: string; date: string; subject: string; refs: GraphRef[] }
export interface GraphHighlight { branch: string; tip: string; base: string; baseTip: string; ahead: number; behind: number; merged: boolean }
export interface GraphPage { label: string; head: string | null; highlight: GraphHighlight | null; commits: GraphCommit[]; hasMore: boolean }
export interface CommitFile { status: string; path: string; from?: string }
export interface CommitDetails {
  hash: string; parents: string[]; author: string; email: string; date: string;
  message: string; files: CommitFile[]; moreFiles: number;
}

export const PALETTE_SIZE = 8;

export interface Segment { from: number; to: number; color: number }
// `top` enters the row from above and ends at the commit's height; `bottom` leaves from
// there to the row below. Each row is therefore drawable on its own.
export interface GraphRow { lane: number; color: number; top: Segment[]; bottom: Segment[] }
export interface GraphLayout { rows: GraphRow[]; laneCount: number; hiddenLanes: number }

type Lane = { hash: string; color: number } | null;

function freeSlot(lanes: Lane[]): number {
  const i = lanes.indexOf(null);
  return i === -1 ? lanes.length : i;
}

/**
 * Lanes for commits in topo order (children before parents). Each lane holds the commit
 * it is waiting for: a commit lands in the first lane waiting for it (or a free one, as a
 * new tip), every other lane waiting for it converges there, and the lane goes on to wait
 * for its first parent. Each further parent reuses a lane already waiting for it or opens
 * one. Colour is fixed when a lane opens and inherited along first parents, so a branch
 * keeps one colour for its whole run.
 */
export function layoutGraph(commits: { hash: string; parents: string[] }[], opts: { maxLanes: number }): GraphLayout {
  let lanes: Lane[] = [];
  let nextColor = 0;
  let laneCount = 0;
  const raw: GraphRow[] = [];

  for (const commit of commits) {
    let lane = lanes.findIndex((l) => l?.hash === commit.hash);
    let color: number;
    if (lane === -1) {
      lane = freeSlot(lanes);
      color = nextColor++ % PALETTE_SIZE;
    } else {
      color = lanes[lane]!.color;
    }

    const top: Segment[] = [];
    lanes.forEach((l, i) => {
      if (l) top.push({ from: i, to: l.hash === commit.hash ? lane : i, color: l.color });
    });
    lanes = lanes.map((l) => (l?.hash === commit.hash ? null : l));

    const [first, ...rest] = commit.parents;
    lanes[lane] = first ? { hash: first, color } : null;

    const bottom: Segment[] = [];
    for (const parent of rest) {
      const waiting = lanes.findIndex((l) => l?.hash === parent);
      if (waiting !== -1) {
        bottom.push({ from: lane, to: waiting, color: lanes[waiting]!.color });
        continue;
      }
      const slot = freeSlot(lanes);
      const pc = nextColor++ % PALETTE_SIZE;
      lanes[slot] = { hash: parent, color: pc };
      bottom.push({ from: lane, to: slot, color: pc });
    }
    // A lane opened by a merge just above starts at the commit: it has no straight run
    // of its own in this row's bottom half beyond the curve already pushed.
    const opened = new Set(bottom.filter((s) => s.from === lane && s.to !== lane && !top.some((t) => t.from === s.to)).map((s) => s.to));
    lanes.forEach((l, i) => {
      if (l && !opened.has(i)) bottom.push({ from: i, to: i, color: l.color });
    });

    while (lanes.length > 0 && lanes[lanes.length - 1] === null) lanes.pop();
    laneCount = Math.max(laneCount, lanes.length, lane + 1, ...top.map((s) => s.from + 1));
    raw.push({ lane, color, top, bottom });
  }

  const cap = Math.max(1, opts.maxLanes);
  const col = (i: number) => Math.min(i, cap - 1);
  const fold = (segs: Segment[]) => {
    const seen = new Set<string>();
    return segs
      .map((s) => ({ from: col(s.from), to: col(s.to), color: s.color }))
      .filter((s) => {
        const key = `${s.from}:${s.to}`;
        if (seen.has(key)) return false;
        seen.add(key);
        return true;
      });
  };
  return {
    rows: raw.map((r) => ({ lane: col(r.lane), color: r.color, top: fold(r.top), bottom: fold(r.bottom) })),
    laneCount,
    hiddenLanes: Math.max(0, laneCount - cap),
  };
}

/**
 * The highlighted branch's own commits within the loaded window: its first-parent run
 * from the tip down to (excluding) the first commit on the base's first-parent run. Empty
 * for a branch fast-forwarded into its base, whose commits are the base's now.
 */
export function highlightChain(commits: { hash: string; parents: string[] }[], tip: string, baseTip: string): Set<string> {
  const byHash = new Map(commits.map((x) => [x.hash, x]));
  const base = new Set<string>();
  for (let h: string | undefined = baseTip; h && byHash.has(h) && !base.has(h); h = byHash.get(h)!.parents[0]) base.add(h);
  const chain = new Set<string>();
  for (let h: string | undefined = tip; h && byHash.has(h) && !base.has(h) && !chain.has(h); h = byHash.get(h)!.parents[0]) chain.add(h);
  return chain;
}

/** The line under the header saying where the highlighted branch stands, or null for none. */
export function highlightSummary(h: GraphHighlight | null, isTicket: boolean): string | null {
  if (!h) return isTicket ? "No branch for this ticket yet" : null;
  if (!h.base) return h.branch;
  if (h.merged) return `${h.branch} · merged into ${h.base}`;
  return `${h.branch} · ${h.ahead} ahead · ${h.behind} behind ${h.base}`;
}
```

If a topology test fails, trace the four-step algorithm by hand on that input before changing either side; the expectations above follow the algorithm's own segment order (top: existing lanes in index order; bottom: merge curves first, then straight runs in index order).

```ts
// Status → the sentence the user reads, kept apart from the API's lowercase strings so
// an API wording change cannot rewrite the UI copy (as useDocs does). A 409 is git
// itself talking, and its words are the useful part.
export function graphErrorMessage(status: number, target: GitTarget, detail?: string): string {
  if (status === 404) {
    if ("session" in target) return "This session no longer exists.";
    if ("ticket" in target) return "This ticket maps to no repo.";
    return "Unknown project.";
  }
  if (status === 409 && detail) return detail;
  if (status === 400) return "This session has no working directory.";
  return "Could not load the git graph.";
}

export function commitErrorMessage(status: number): string {
  return status === 404 ? "Commit not found." : "Could not load the commit.";
}

export function appendPage(prev: GraphPage, next: GraphPage): GraphPage {
  const have = new Set(prev.commits.map((c) => c.hash));
  return { ...prev, commits: [...prev.commits, ...next.commits.filter((c) => !have.has(c.hash))], hasMore: next.hasMore };
}

async function errorDetail(res: Response): Promise<string | undefined> {
  try { return ((await res.json()) as { error?: string }).error; } catch { return undefined; }
}

// `reload` is a counter the caller bumps — the graph is a snapshot, refreshed by hand.
export function useGitGraph(token: string, target: GitTarget, reload: number) {
  const [page, setPage] = useState<GraphPage | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [loadingMore, setLoadingMore] = useState(false);
  const [moreError, setMoreError] = useState(false);
  // The serialised query, not the object: a fresh literal each render would re-fetch forever.
  const q = gitTargetQuery(target);

  useEffect(() => {
    let alive = true;
    setPage(null);
    setError(null);
    setMoreError(false);
    apiFetch(token, `/api/git/graph?${q}`)
      .then(async (res) => {
        if (!alive) return;
        if (!res.ok) setError(graphErrorMessage(res.status, target, await errorDetail(res)));
        else setPage((await res.json()) as GraphPage);
      })
      .catch(() => { if (alive) setError("Could not load the git graph."); });
    return () => { alive = false; };
    // `target` is represented by `q`.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [token, q, reload]);

  const loadMore = useCallback(() => {
    if (!page || !page.hasMore || loadingMore) return;
    setLoadingMore(true);
    setMoreError(false);
    apiFetch(token, `/api/git/graph?${q}&skip=${page.commits.length}`)
      .then(async (res) => {
        if (!res.ok) { setMoreError(true); return; }
        const next = (await res.json()) as GraphPage;
        setPage((prev) => (prev ? appendPage(prev, next) : prev));
      })
      .catch(() => setMoreError(true))
      .finally(() => setLoadingMore(false));
  }, [token, q, page, loadingMore]);

  return { page, error, loadMore, loadingMore, moreError };
}

export function useGitCommit(token: string, target: GitTarget, hash: string | null) {
  const [details, setDetails] = useState<CommitDetails | null>(null);
  const [error, setError] = useState<string | null>(null);
  const q = gitTargetQuery(target);
  useEffect(() => {
    setDetails(null);
    setError(null);
    if (!hash) return;
    let alive = true;
    apiFetch(token, `/api/git/commit?${q}&hash=${encodeURIComponent(hash)}`)
      .then(async (res) => {
        if (!alive) return;
        if (!res.ok) setError(commitErrorMessage(res.status));
        else setDetails((await res.json()) as CommitDetails);
      })
      .catch(() => { if (alive) setError("Could not load the commit."); });
    return () => { alive = false; };
  }, [token, q, hash]);
  return { details, error };
}
```

```tsx
// src/components/GitGraphView.tsx
"use client";
import { ChevronLeft, FolderGit2, RotateCw, X } from "lucide-react";
import { useEffect, useMemo, useRef, useState } from "react";
import { highlightChain, highlightSummary, layoutGraph, type GraphCommit, type GraphRow } from "@/lib/gitGraph";
import { useGitCommit, useGitGraph, type GitTarget } from "@/lib/useGitGraph";
import { relativeTime } from "@/lib/relativeTime";

const LANE_W = 12;
const NARROW = "(max-width: 479px)";

function useNarrow(): boolean {
  const [narrow, setNarrow] = useState(() => typeof window !== "undefined" && window.matchMedia(NARROW).matches);
  useEffect(() => {
    const mq = window.matchMedia(NARROW);
    const on = () => setNarrow(mq.matches);
    mq.addEventListener("change", on);
    return () => mq.removeEventListener("change", on);
  }, []);
  return narrow;
}

function seg(x1: number, y1: number, x2: number, y2: number): string {
  if (x1 === x2) return `M${x1} ${y1}V${y2}`;
  const my = (y1 + y2) / 2;
  return `M${x1} ${y1}C${x1} ${my} ${x2} ${my} ${x2} ${y2}`;
}

function Lanes({ row, cols, h, hl }: { row: GraphRow; cols: number; h: number; hl: boolean }) {
  const x = (i: number) => i * LANE_W + LANE_W / 2;
  const mid = h / 2;
  const stroke = (c: number) => `var(--graph-${c})`;
  return (
    <svg width={cols * LANE_W} height={h} aria-hidden="true">
      {row.top.map((s, k) => <path key={`t${k}`} d={seg(x(s.from), 0, x(s.to), mid)} stroke={stroke(s.color)} strokeWidth={2} fill="none" />)}
      {row.bottom.map((s, k) => <path key={`b${k}`} d={seg(x(s.from), mid, x(s.to), h)} stroke={stroke(s.color)} strokeWidth={2} fill="none" />)}
      <circle cx={x(row.lane)} cy={mid} r={4} fill={hl ? "var(--accent)" : stroke(row.color)} stroke="var(--bg)" strokeWidth={1.5} />
    </svg>
  );
}

function Refs({ commit, branch }: { commit: GraphCommit; branch: string | null }) {
  if (commit.refs.length === 0) return null;
  return (
    <span className="git-refs">
      {commit.refs.map((r) => (
        <span
          key={`${r.kind}:${r.name}`}
          className={`git-ref ${r.kind}${r.kind === "local" && r.name === branch ? " hl" : ""}`}
          title={r.mojito ? "Mojito worktree" : r.worktree ? "Checked out in a worktree" : r.kind === "tag" ? "Tag" : undefined}
        >
          {r.worktree && <FolderGit2 size={10} aria-hidden="true" />}
          {r.name}
        </span>
      ))}
    </span>
  );
}

export default function GitGraphView(
  { token, target, label, selected, onSelect, onBack }:
  {
    token: string;
    target: GitTarget;
    label: string;
    // The open commit lives in the url (`?commit=`), so Back closes the sheet before it
    // leaves the view and a single commit is linkable — DocsView's `selected`, again.
    selected: string | null;
    onSelect: (hash: string) => void;
    onBack: () => void;
  },
) {
  const [reload, setReload] = useState(0);
  const { page, error, loadMore, loadingMore, moreError } = useGitGraph(token, target, reload);
  const narrow = useNarrow();
  const rowH = narrow ? 40 : 28;
  const layout = useMemo(
    () => (page ? layoutGraph(page.commits, { maxLanes: narrow ? 5 : 12 }) : null),
    [page, narrow],
  );
  const chain = useMemo(
    () => (page?.highlight ? highlightChain(page.commits, page.highlight.tip, page.highlight.baseTip) : new Set<string>()),
    [page],
  );
  const summary = page ? highlightSummary(page.highlight, "ticket" in target) : null;

  // Once per load: bring the highlighted tip on screen if it is not among the first rows.
  const scrolled = useRef(false);
  useEffect(() => { scrolled.current = false; }, [reload]);
  useEffect(() => {
    const tip = page?.highlight?.tip;
    if (!tip || scrolled.current) return;
    scrolled.current = true;
    const i = page!.commits.findIndex((c) => c.hash === tip);
    if (i > 10) document.getElementById(`git-${tip}`)?.scrollIntoView({ block: "center" });
  }, [page]);

  const cols = layout ? Math.min(layout.laneCount, narrow ? 5 : 12) || 1 : 1;

  return (
    <div className="docs-root">
      <header className="docs-head">
        <button className="back icon" aria-label="Back" onClick={onBack}>
          <ChevronLeft size={20} aria-hidden="true" />
        </button>
        <span className="name">{`${page?.label ?? label} · git`}</span>
        <span className="grow" />
        {layout && layout.hiddenLanes > 0 && <span className="git-lanes-more">+{layout.hiddenLanes} lanes</span>}
        <button className="btn sm icon" aria-label="Reload" onClick={() => setReload((n) => n + 1)}>
          <RotateCw size={14} aria-hidden="true" />
        </button>
      </header>
      {summary && <div className={`git-strip${page?.highlight ? " hl" : ""}`}>{summary}</div>}
      <div className="docs-scroll">
        {error ? <p className="empty">{error}</p>
        : !page || !layout ? <p className="empty">Loading…</p>
        : page.commits.length === 0 ? <p className="empty">No commits yet.</p>
        : (
          <>
            {page.commits.map((c, i) => {
              const hl = chain.has(c.hash);
              return (
                <button
                  key={c.hash}
                  id={`git-${c.hash}`}
                  className={`git-row${hl ? " hl" : chain.size > 0 ? " dim" : ""}`}
                  style={{ height: rowH }}
                  aria-current={c.hash === selected ? "true" : undefined}
                  onClick={() => onSelect(c.hash)}
                >
                  <Lanes row={layout.rows[i]} cols={cols} h={rowH} hl={hl} />
                  <span className="git-text">
                    <span style={{ display: "flex", gap: 6, minWidth: 0, flex: 1, alignItems: "center" }}>
                      <Refs commit={c} branch={page.highlight?.branch ?? null} />
                      <span className="git-subj">{c.subject}</span>
                    </span>
                    <span className="git-meta">{c.hash.slice(0, 7)} · {relativeTime(c.date)}</span>
                  </span>
                </button>
              );
            })}
            {page.hasMore && (
              <button className="btn ghost sm git-more" disabled={loadingMore} onClick={loadMore}>
                {loadingMore ? "Loading…" : moreError ? "Retry" : "Load more"}
              </button>
            )}
          </>
        )}
      </div>
      {selected && <CommitSheet token={token} target={target} hash={selected} onClose={onBack} />}
    </div>
  );
}

function CommitSheet({ token, target, hash, onClose }: { token: string; target: GitTarget; hash: string; onClose: () => void }) {
  const { details, error } = useGitCommit(token, target, hash);
  return (
    <div className="sheet-backdrop git-sheet" onClick={onClose}>
      <div className="sheet" role="dialog" aria-label={`Commit ${hash.slice(0, 7)}`} onClick={(e) => e.stopPropagation()}>
        <div style={{ display: "flex", alignItems: "center", gap: 8 }}>
          <h3 className="sheet-title" style={{ margin: 0, flex: 1 }}>{hash.slice(0, 10)}</h3>
          <button className="btn sm icon" aria-label="Close" onClick={onClose}>
            <X size={14} aria-hidden="true" />
          </button>
        </div>
        {error ? <p className="err-text">{error}</p>
        : !details ? <p className="empty">Loading…</p>
        : (
          <>
            <p className="git-meta" style={{ marginTop: 8, whiteSpace: "normal" }}>
              {details.author} &lt;{details.email}&gt; · {new Date(details.date).toLocaleString()}
            </p>
            <p className="git-meta" style={{ whiteSpace: "normal", overflowWrap: "anywhere" }}>{details.hash}</p>
            <pre className="git-msg">{details.message}</pre>
            <ul className="git-files">
              {details.files.map((f) => (
                <li key={`${f.status}:${f.from ?? ""}:${f.path}`}>
                  <span className={`st ${f.status}`}>{f.status}</span>
                  <span>{f.from ? `${f.from} → ${f.path}` : f.path}</span>
                </li>
              ))}
            </ul>
            {details.moreFiles > 0 && <p className="git-meta">…and {details.moreFiles} more</p>}
          </>
        )}
      </div>
    </div>
  );
}
```

```markdown
- **Git graph**: a read-only branch/commit graph of a repo, reachable from a project
  divider (`/git/project/<name>`), a ticket's launch sheet (`/git/ticket/<id>`) and a
  terminal header (`/session/<id>/git`, an overlay like docs so the pty stays attached).
  The server reads raw commits (`git log --topo-order`, NUL/RS-separated so no subject can
  break the parse), refs via `for-each-ref` rather than `%D` (ambiguous for branch names
  with `,` or `->`) and worktrees, and answers JSON (`src/server/gitGraph.ts`,
  `gitTarget.ts`); lanes are assigned on the client by the pure `layoutGraph`
  (`src/lib/gitGraph.ts`). It never fetches: the graph is whatever the last fetch left.
  The highlighted branch's ahead/behind is `rev-list --left-right --count` against
  `origin/<default>`, exact outside the loaded window. Commit hashes are validated
  (`^[0-9a-f]{7,40}$`) before any git call and resolved through `rev-parse` before
  `show`, so a query value never reaches git as a flag.
```
