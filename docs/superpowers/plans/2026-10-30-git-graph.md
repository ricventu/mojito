# Git graph (v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only, phone-first git graph per project (`/git/:project`), with a ticket's branch highlighted against `origin/<default>`, commit details and per-file diffs.

**Architecture:** The server reads refs, commits, worktrees, details and diffs with git (pure parsers over an injected `GitRun`, three GET routes under `/api/projects/:name/git/`). The client pages commits with `useInfiniteQuery`, lays out lanes with a pure `layoutGraph`, and keeps all view state (`ticket`, `commit`, `file`, `from`) in the url.

**Tech Stack:** Node 22, Hono 4, vitest; React 19, react-router, TanStack Query, Tailwind 4, shadcn `Sheet`, lucide.

**Spec:** `docs/superpowers/specs/2026-10-30-git-graph-design.md` — read it first; this plan does not repeat its rationale.

## Global Constraints

- Work only in `apps/` and `packages/` (plus the v2 `CLAUDE.md` and this plan); never v1's `src/`, `server.ts`, `tests/`.
- Everything English: code, comments, copy, server errors.
- Read-only git: never `fetch`, never any write. Reads run with a **10 s** timeout; Pull/Push keep **120 s**.
- Hash shape `^[0-9a-f]{7,40}$`, checked before any git call; resolved with `rev-parse --verify -q --end-of-options <hash>^{commit}`; only the full hash reaches later calls.
- Ticket shape `^[A-Za-z][A-Za-z0-9]*-\d+$`.
- Page size **200** (git asked for 201); files cap **300**; diff cap **256 KB** (262 144 chars), cut at a line end.
- Error bodies are always `{ error }`; git failures → 409 with git's output, first 500 chars.
- Web: pure logic in `src/lib` with node tests; Tailwind utilities + shadcn only; lucide icons with `size`; overlay sheets draw their own ✕ (`showCloseButton={false}`) paying the safe-area insets.
- Shared types are consumed as source from `@mojito/shared`.
- Server git tests that run real git set `GIT_CONFIG_GLOBAL=/dev/null` and `GIT_CONFIG_NOSYSTEM=1` (as `test/git/sync.test.ts`).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A branch name containing the ticket id as a prefix of a longer id** (`ric-5050` for `RIC-505`) must not be highlighted — Task 2 tests it.
2. **A path with spaces, quotes, `*` or non-ASCII** must list correctly and diff the right file (`-z` and `:(literal)`) — Task 4's integration test commits `dir/we ird*.txt`.
3. **A commit opened from a url whose hash is unknown or malformed** shows "Commit not found" / a 400, never a crash, and the sheet still closes — Task 5 route tests + Task 9 error branch.
4. **A late page landing after Reload** must not append to the reloaded graph — Task 8 uses `useInfiniteQuery` keyed per (project, ticket) and Reload resets the query (`resetQueries`), not appending.
5. **A detached HEAD or a repo with no `origin`** must still draw the graph (no strip, or the branch alone) — Task 3 integration test detaches HEAD in a clone with no remote.
